# PapAssist (Paper_Read_Assist)

A reading assistant for mathematics papers. Give it a paper as LaTeX source,
read it in your browser, and hover over any symbol or technical term to see
what it means in this paper, where it was introduced, and where the
explanation came from (this paper, a cited paper, standard notation, or an
LLM, always labelled).

Status: planning. See [docs/PLAN.md](docs/PLAN.md) for the design, the phased
roadmap, and the open decisions before the prototype is built.
